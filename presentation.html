Алхимическая книга
Справочник алхимика

Тёплый сказочный справочник по рецептам алхимии: сайт в виде книги и Telegram-бот с теми же данными.

Открыть книгу YupLand

Зачем это нужно

Быстрый «справочник под рукой»

Игрокам удобно смотреть состав, время, подсказки по профиту и переходить между связанными рецептами — без лишнего шума и без «финансовых обещаний»: только игровой контекст.

Каналы

Сайт в приоритете, бот рядом

  • Сайт-книга — разворот: список слева, карточка справа; фильтр по разделам.
  • Манускрипт — полноэкранное дерево рецептов по выбранному разделу.
  • Боты — Python и Node (grammY): те же рецепты из одного файла.

Архитектура данных

Один источник правды

Все рецепты живут в recipes.json. Состав может быть строкой ingredients или блоками ingredientsBlocks «как в игре». Импорт с вики YupLand — отдельным скриптом; проверка — node tools/check_recipes.js.

Детали интерфейса

Удобство и магия книги

  • Перекрёстные ссылки: если компонент совпадает с названием другого рецепта — открывается его страница.
  • Иконки валют/токенов из assets/*.png, превью по imageUrl.
  • Ссылки на вики — поле wikiUrl.

Контент и тон

Аккуратно и дружелюбно

Тон — тёплый, сказочный, чуть таинственный; без токсичности, мата и политики. «Профит» — только игровой смысл, без отсылки к деньгам и инвестициям. Лор YupLand не переписываем «с нуля»: опираемся на существующие формулировки.

Локально

Как открыть

  • Сайт: из корня проекта py -m http.server 8000 → 127.0.0.1:8000 (не через file://).
  • Бот: переменные TELEGRAM_BOT_TOKEN / BOT_TOKEN, опционально SITE_URL.

О слайдах и PDF

HTML и PDF

Этот файл — самодостаточная презентация в духе визуального языка YupLand: тёмный фон, мягкие градиенты, бирюза и фиолет как на современных Web3-лендингах, золото — отсылка к «книге» справочника.

PDF файлом: из корня проекта выполни npm run export:presentation-pdf — появится exports/presentation.pdf (нужны npm install и Chromium для Playwright: npx playwright install chromium).

Из браузера: Ctrl+P → принтер «Сохранить как PDF» — каждый слайд на отдельной странице (A4 альбомная ориентация).
