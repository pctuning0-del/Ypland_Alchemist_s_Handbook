## Project: Ypland Alchemist’s Handbook

Мини-сайт «книга» + Telegram-бот со справочником рецептов алхимии для игры. Алхимия = создание новых предметов из старых; «профит» = игровая выгода/преимущество (не деньги, не инвестиции).

## Primary goals

- Дать быстрый, приятный “справочник под рукой” по рецептам алхимии.
- Держать проект максимально простым: данные в одном месте, лёгкая поддержка.

## Audience

Широкая аудитория игроков.

## Product priorities

Оба канала важны, но приоритет — **сайт-книга**. Бот — вспомогательный вход и быстрый доступ к тем же данным.

## Voice & style (RU first, EN optional)

- **Тон**: тёплый + сказочный + чуть таинственный.
- **Подача**: коротко, образно, без агрессии.
- **Персона**: не персонализировать под конкретного человека — **не использовать обращение “Саша”** (делать нейтрально).
- **Языки**: по умолчанию русский; допускается английская версия/дублирование, если это не усложняет структуру.

## Content boundaries (very important)

- **Профит только игровой**: не звучать как финансовые советы, не обещать “заработок”, не давать гарантий результата.
- **Никакой токсичности**: без унижений игроков/ошибок, без пассивной агрессии.
- **Без мата**.
- **Без политики**.

## Lore rules

Лор Юпленда — аккуратно: лучше опираться на существующие формулировки/настроение. Новое добавлять только если оно не конфликтует и не выглядит “канонным заявлением”.

## Data & repo rules

- **Single source of truth**: все рецепты живут в `recipes.json`. Не дублировать рецепты в коде, не заводить второй формат, если нет явной причины.
- **No secrets in git**: никогда не коммитить токены/ключи/секреты. `.env` должен оставаться локальным.
- **Схема записи рецепта** (минимум то, что читают сайт и боты): `id`, `name`, `section` (опционально), `profitHint`, `time`, `ingredients`, `story`, опционально `wikiUrl`, `imageUrl`.
- **`ingredients`**: одна строка, части через **`"; "`** (точка с запятой и пробел). На сайте каждая часть — отдельная строка; первый числовой токен — количество (жирным). Для **перекрёстных ссылок**: если текст компонента после количества **точно совпадает** (после нормализации пробелов) с полем **`name`** другого рецепта в том же `recipes.json`, он кликабелен и открывает тот рецепт.
- **`story`**: может быть пустой строкой; импортёр с вики не заполняет длинный текст со страницы.
- **`profitHint`**: короткая игровая метка (например результат крафта); **не дублировать** текст раздела из `section`.
- При изменении полей — обновить **сайт** (`main.js`) и **оба бота** (`bot.py`, `index.js`), плюс при необходимости **импортёр** (`tools/build_recipes_from_yupland.mjs`).

## Tech notes (current structure)

- Сайт: `index.html`, `styles.css`, `main.js` (загружает `recipes.json` через `fetch`, ссылки между рецептами по совпадению `name`).
- Python-бот: `bot.py` (читает `recipes.json`, кнопки, команды; состав в сообщении построчно, количество в `<b>`).
- Node-бот (альтернатива): `index.js` + `package.json` (grammY).
- Импорт с вики YupLand: Playwright + канал **Edge** (`tools/build_recipes_from_yupland.mjs`), манифест `tools/yupland_import_manifest.json`, команда **`npm run import:yupland`** (перезаписывает `recipes.json`).
- Проверка данных: **`node tools/check_recipes.js`**.

## How to run (local)

- Сайт (важно: не через `file://`):
  - `py -m http.server 8000`
  - открыть `http://127.0.0.1:8000`
- Python bot:
  - `py -m pip install -r requirements.txt`
  - env: `TELEGRAM_BOT_TOKEN`, optionally `SITE_URL`
  - `py bot.py`
- Node bot:
  - `npm install`
  - `.env` from `.env.example` (set `BOT_TOKEN`, optional `SITE_URL`)
  - `npm start`
- Импорт рецептов с вики (локально, нужны Node и Edge):
  - заполнить `tools/yupland_import_manifest.json`
  - `npm run import:yupland`

## When editing, prefer

- Маленькие, безопасные правки.
- Ясные тексты интерфейса и сообщений бота.
- Совместимость данных: изменения схемы `recipes.json` — только вместе с обновлением сайта и бота.
